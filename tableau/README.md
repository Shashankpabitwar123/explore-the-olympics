# Open and edit the dashboard

1. [Download Explore_the_Olympics.twbx](https://github.com/Shashankpabitwar123/explore-the-olympics/raw/refs/heads/main/tableau/Explore_the_Olympics.twbx).
2. Open it in Tableau Desktop or the Tableau Public desktop application.
3. Select **Olympic Explorer**. Presentation Mode gives the dashboard more room.
4. Start with a gallery landmark, then choose an edition, sport, category and event. Use Reset to return to Paris 2024 women's 100 m.

The workbook is the published Tableau Public download retrieved on 1 October 2026. Its embedded Hyper extract and artwork travel with the file. Viewing the saved dashboard does not require reconnecting to the original CSV paths.

The fixed dashboard canvas is **1513 × 1039**. Smaller windows may need scrolling. The workbook contains editable worksheets, calculations, parameter actions and image objects.

For editing, save a copy first. Unhide the underlying sheets as needed and inspect the **Explore selection** parameter and the dashboard actions. Artwork is embedded imagery; labels, results and controls are Tableau elements.

The saved text-file connection can contain the author's temporary source path. The embedded extract is the portable viewing source. Refreshing from CSV requires preparing and reconnecting the combined presentation table; the five source tables in this repository are not a direct replacement for that table. [See the model notes](../docs/dashboard_notes.md).
